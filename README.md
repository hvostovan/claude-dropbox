# claude-dropbox

Односторонний канал: с VPS (или из чата с Клодом) файлы кладутся сюда и пушатся в `main`, а на личном ноутбуке фоновый скрипт каждые несколько секунд делает `git pull` — так файлы попадают на комп, даже когда включён корпоративный VPN и прямой доступ к VPS/Google Диску/OneDrive закрыт. GitHub у корпоративного фильтра разрешён, поэтому используется как посредник.

## Структура

Одна папка — один проект/задача:

```
openspec-sdd/   — пример: подготовка к OpenSpec SDD
<новый-проект>/ — под каждую новую задачу своя папка
```

Внутри папки — любые `.md` и другие файлы по задаче.

## Как пользоваться

Просто попроси Клода в чате (в сессии Claude Code, подключённой к VPS): "создай в dropbox проект <имя>" / "положи такой-то файл в dropbox/<проект>". Клод создаст/обновит файл в нужной папке этого репозитория и сразу запушит в `main` — без лишних подтверждений, это рутинная операция.

На стороне ноутбука никакого фонового синка нет — файлы читаются прямо на github.com/hvostovan/claude-dropbox через браузер (доступ туда у корпоративного фильтра разрешён).

## Важно

Это открытый (для процесса синка) канал только **из VPS наружу к личному ноутбуку**, не наоборот. Ничего секретного (пароли, ключи, реальные данные) сюда не кладём — репозиторий приватный, но сама суть канала — что файлы уезжают на машину, которая физически бывает подключена к корпоративной сети.
