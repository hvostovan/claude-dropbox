# OpenSpec SDD — обучение команды

Материалы для двухдневного очного обучения команды процессу SDD (Spec-Driven Development) на
GigaCode/OpenSpec. Всё текстовое — здесь; сама реализация (код) идёт в отдельном боевом
репозитории, не в этом.

## Структура

- **`workshop-plan.md`** — план двух дней: расписание по блокам, кто что делает.
- **`lead-guide.md`** — инструкция тимлида: подготовка репозитория (master + ветка по стеку),
  что делать в день обучения.
- **`role-playbooks.md`** — по шагам для каждой из 5 ролей (Product Owner, системный аналитик,
  вся команда на валидации, разработчик, QA): команды GigaCode, промпты, вход/выход.
- **`qa-guide.md`** — подробности тестирования (Этап 5), вынесено отдельно от
  `role-playbooks.md`, чтобы не перегружать основной файл.
- **`task.md`** — сама задача (планировщик спринтовых задач) и стеки по командам —
  презентационный материал, показывается команде на старте, не часть боевого репозитория.
- **`skills/`** — кастомные GigaCode-скилы.
- **`teams/<стек>/`** — готовое содержимое `openspec/` под каждый стек, переносится в ветки
  боевого репозитория.

## С чего начать

- **Lead** — `lead-guide.md`, затем `workshop-plan.md`.
- **Любая роль в команде** — `role-playbooks.md`.
- **QA** — `role-playbooks.md`, Этап 5, и `qa-guide.md` для деталей.
