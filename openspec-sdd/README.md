# OpenSpec SDD — обучение команды

Материалы для двухдневного очного обучения команды процессу SDD (Spec-Driven Development) на
GigaCode/OpenSpec. Всё текстовое — здесь; сама реализация (код) идёт в отдельном боевом
репозитории, не в этом.

## Структура

- **`team-training-plan.md`** — план двух дней: расписание по блокам, кто что делает.
- **`lead-plan.md`** — инструкция тимлида: подготовка репозитория (master + ветка по стеку),
  что делать в день обучения.
- **`role-playbooks.md`** — по шагам для каждой из 5 ролей (Product Owner, системный аналитик,
  вся команда на валидации, разработчик, QA): команды GigaCode, промпты, вход/выход.
- **`qa-testing-guide.md`** — подробности тестирования (Этап 5), вынесено отдельно от
  `role-playbooks.md`, чтобы не перегружать основной файл.
- **`task.md`** — сама задача (планировщик спринтовых задач) и стеки по командам —
  презентационный материал, показывается команде на старте, не часть боевого репозитория.
- **`skills/`** — кастомные GigaCode-скилы. Сейчас: подрезанный `openspec-intent`
  (он же `sber-intent`) — без рамки "ежедневная сессия", с явным требованием сохранять
  `intent.md` файлом.
- **`teams/<стек>/`** — готовое содержимое `openspec/` под каждый стек (Python/JavaScript/Java):
  переносится в соответствующие git-ветки боевого репозитория при подготовке.

## С чего начать

- **Lead** — `lead-plan.md`, затем `team-training-plan.md`.
- **Любая роль в команде** — `role-playbooks.md`.
- **QA** — `role-playbooks.md`, Этап 5, и `qa-testing-guide.md` для деталей.
