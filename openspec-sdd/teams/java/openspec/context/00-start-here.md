# Start Here
> Только навигация и главные запреты, не само знание. Держать на один экран.

Работаешь с продуктом: планировщик спринтовых задач (эпики → задачи → исполнители).
Полное описание задачи — см. `task.md` в корне репозитория `claude-dropbox`.

## Перед началом любой задачи
1. Прочитай 01-architecture.md.
2. Прочитай 02-engineering-standards.md.
3. Не делай изменений вне scope задачи.
4. Не хватает контекста — сформулируй, какого, и не угадывай.

## Главные запреты
- Не подключать БД — хранение только в памяти процесса.
- Не подключать отдельный JS UI-фреймворк — рендеринг только на сервере.
